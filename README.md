## 🔹 Git Commands Used

### 1. git init
```bash
git init
```
- Creates a new Git repository in a project folder.
- Initializes Git and starts tracking files in that directory.

---

### 2. git status
```bash
git status
```
- Shows the current state of the working directory.
- Displays modified, staged, and untracked files.

---

### 3. git add
```bash
git add .
```
- Moves changes from the working directory to the staging area.
- Prepares selected files to be committed.

---

### 4. git commit
```bash
git commit -m "initial commit"
```
- Saves the staged changes permanently in the repository.
- Creates a snapshot of the project with a message.

---

### 5. git remote
```bash
git remote add origin https://github.com/your-username/devops.git
```
- Connects the local repository to a remote repository (GitHub).
- Allows pushing and pulling code.

---

### 6. git push
```bash
git push origin master
```
- Uploads local committed changes to the remote repository.
- Updates the remote branch with the latest code.

---

### 7. git clone
```bash
git clone https://github.com/your-username/devops.git
```
- Copies a remote repository to your local system.
- Creates a complete working project with all files and commit history.

---

### 8. git branch
```bash
git branch f1
```
- Creates or lists branches in a repository.
- Allows parallel development without affecting the main branch.

---

### 9. git checkout
```bash
git checkout f1
```
- Switches between branches.
- Lets you work on different versions of the project.

---

### 10. git fetch
```bash
git fetch origin
```
- Downloads the latest changes from the remote repository.
- Updates tracking branches but does not merge automatically.

---

### 11. git pull
```bash
git pull origin master
```
- Fetches and merges changes from the remote repository.
- Updates your local branch with the latest remote changes.

---

### 12. git log
```bash
git log
```
- Displays the commit history.
- Shows commit ID, author, date, and commit message.

---

### 13. git merge
```bash
git merge f1
```
- Combines changes from one branch into another branch.
- Integrates development work into a single branch.

---
